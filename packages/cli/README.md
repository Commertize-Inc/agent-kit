# @commertize/agent-kit

Templates and a CLI for running your own agent against Commertize, on your own framework and keys.

```bash
npx @commertize/agent-kit init desk-watcher
npx @commertize/agent-kit routes
npx @commertize/agent-kit mcp desk-watcher --server /absolute/path/to/mcp-server/dist/index.js
```

Full documentation, route status and templates: https://github.com/Commertize-Inc/agent-kit#readme
