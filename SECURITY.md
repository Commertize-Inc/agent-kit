# Security policy

Please report suspected vulnerabilities privately by email to **support@commertize.com** with the subject line "Security report: agent-kit". Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the affected package and version. We aim to acknowledge reports promptly and keep reporters informed while we investigate. We are glad to credit you in the release notes if you wish. This policy creates no contractual obligation and offers no bounty.

In scope: the CLI, library and templates in this repository. Out of scope: Commertize's hosted services (report those to the same address, but they are not covered by this repository's releases), and the model, framework or key storage you connect to a template.

Your keys are yours: the kit never stores or uploads your session token, API key or agent seed. If you find a path where it does, that is a vulnerability; please report it.

Please act in good faith: do not access data that is not yours, do not degrade service for others, and give us reasonable time to fix an issue before disclosing it.
